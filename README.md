# Caffè Strada Website

This repository contains a simple static website for **Caffè Strada**, a smoke-free café located in Abdoun, Amman. The site uses a clean, European-inspired design with warm tones and minimal typography.

## Pages

- `index.html` &ndash; Home page with a hero image and quick links.
- `menu.html` &ndash; Full menu of espresso drinks, paninis, salads, desserts, and teas.
- `about.html` &ndash; Background about the café and its inspiration.
- `gallery.html` &ndash; Photo gallery of the interior, exterior, and offerings.
- `contact.html` &ndash; Address, hours, a contact form, and map.

The website is styled with `assets/css/style.css` and uses a small script in `assets/js/script.js` for basic functionality.

## Viewing

Open any of the HTML files in a web browser to view the site. All images are sourced from Unsplash and fonts from Google Fonts, so an internet connection is required to load them.
